# AI Usage

## Tool Used

ChatGPT

## Areas Where AI Assisted

1. Database schema brainstorming.
2. Strategy Pattern design.
3. Evaluator architecture design.
4. Laravel migration generation.
5. README structure.
6. Architecture documentation.

## Human Decisions

The following adjustments were made after reviewing AI suggestions:

* Modified database schema to support option images.
* Refactored evaluation logic into QuizEvaluationService.
* Improved question extensibility using a Strategy Pattern.
* Added JSON metadata storage for flexible question configuration.

## Validation

All generated code was reviewed, tested, and adjusted manually before integration into the application.

## Lessons Learned

AI was primarily used as a development assistant and architectural review tool. Final implementation decisions were made by the developer.
